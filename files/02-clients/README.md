# Clients

**One folder per client**, named after them (for example `Hollins Lettings`). Put everything about that client inside: notes after a call, call transcripts, emails, their brief, photos, old proposals, anything. Rough is fine.

That's all Proposal Writing OS needs. When you want a proposal, open the app's **Clients** page and press **Write proposal**. Claude reads everything in the folder (and your emails and calls with them, if those are connected) and writes it in your brand.

- **New client?** Make a folder and drop something in, then press **Check for new folders** in the app. Or press **New proposal** and type their name: Claude makes the folder for you.
- **Claude keeps the folders full.** When it finds an email or a call with a client, it saves a short summary into their folder, so everything is in one place.
- **Save your proposals here too.** When you save a proposal as a PDF, save it in the client's folder.

Naming: start file names with the date, `YYYY-MM-DD short description`, so they sort in order. Claude follows this when it files things for you (see `.claude/skills/file-it`).
